# CSS Box Model & Spacing Cheatsheet

เอกสารสรุปทบทวนความจำสำหรับ **CSS Box Model** และ **Shorthand Rules** (อ่านจบใน 2 นาที)

---

## 1. ผัง 4 ชั้นของ Box Model (ในสุด -> นอกสุด)

```text
┌───────────────────────────────────────────────────────────┐
│ MARGIN (สีส้ม)   : เว้นระยะห่างภายนอก ผลักกล่องอื่นออกไป    │
│ ┌───────────────────────────────────────────────────────┐ │
│ │ BORDER (สีเหลือง): เส้นขอบ / ผนังกล่อง มีความหนาและสี  │ │
│ │ ┌───────────────────────────────────────────────────┐ │ │
│ │ │ PADDING (สีเขียว): โฟมกันกระแทกข้างใน ดันของเข้าใน  │ │ │
│ │ │ ┌───────────────────────────────────────────────┐ │ │ │
│ │ │ │ CONTENT (สีฟ้า): ข้อความ รูปภาพ ตัวสินค้าจริง    │ │ │ │
│ │ │ └───────────────────────────────────────────────┘ │ │ │
│ │ └───────────────────────────────────────────────────┘ │ │
│ └───────────────────────────────────────────────────────┘ │
└───────────────────────────────────────────────────────────┘
```

| ชั้น | หน้าที่ | สีใน DevTools (F12) | มีสีพื้นหลังไหม? |
| :--- | :--- | :--- | :--- |
| **Content** | พื้นที่แสดงผลข้อความ/รูปภาพ | สีฟ้า (Blue) | มี |
| **Padding** | ขยายพื้นที่ภายในขอบกล่อง | สีเขียว (Green) | มี (ตามสีพื้นหลังกล่อง) |
| **Border** | เส้นขอบกล่อง | สีเหลือง/เทา (Yellow) | ตามสีขอบที่ตั้งไว้ |
| **Margin** | ช่องว่างเว้นระยะห่างภายนอก | สีส้ม (Orange) | **โปร่งใสเสมอ (ไม่มีสี)** |

## 2. กฎการนับ Shorthand (หมุนตามเข็มนาฬิกา 12 -> 3 -> 6 -> 9)

ใช้ได้ทั้ง `padding` และ `margin`

```text
             12 นาฬิกา (TOP)
                   ▲
                   │
9 นาฬิกา (LEFT) ◄──┼──► 3 นาฬิกา (RIGHT)
                   │
                   ▼
             6 นาฬิกา (BOTTOM)
```

| จำนวนค่า | รูปแบบ | ความหมาย | ตัวอย่างจริง |
| :---: | :--- | :--- | :--- |
| **4 ตัว** | `บน ขวา ล่าง ซ้าย` | ตามเข็มนาฬิกาครบ 4 ทิศ | `margin: 10px 20px 30px 40px;` |
| **3 ตัว** | `บน (ซ้ายขวา) ล่าง` | ตัวกลางคุมทั้งสองข้าง | `padding: 10px 20px 30px;` |
| **2 ตัว** | `(บนล่าง) (ซ้ายขวา)` | ตัวหน้าคุมแนวตั้ง ตัวหลังคุมแนวนอน | `padding: 12px 24px;`<br>`margin: 2rem auto;` |
| **1 ตัว** | `ทุกทิศ` | ขนาดเท่ากันทั้ง 4 ด้าน | `padding: 16px;` |

> **สูตรช่วยจำ:** ขาดด้านไหน ให้มองไปฝั่งตรงข้าม (ขาดซ้าย -> ใช้เท่าขวา, ขาดล่าง -> ใช้เท่าบน)

## 3. กฎเหล็ก `box-sizing`: กันเลย์เอาต์ระเบิด

### ค่าเริ่มต้นของเบราว์เซอร์: `content-box` (พังง่าย)
- $\text{ความกว้างจริง} = \text{width} + \text{padding ซ้ายขวา} + \text{border ซ้ายขวา}$
- สั่ง `width: 300px; padding: 20px;` $\to$ กล่องจะบวมกลายเป็น **340px**

### มาตรฐานอุตสาหกรรม: `border-box` (ต้องใช้เสมอ)
- $\text{ความกว้างจริง} = \text{width ที่สั่งไว้เป๊ะๆ}$
- สั่ง `width: 300px; padding: 20px;` $\to$ กล่องคงที่ **300px** (Padding ดันกินพื้นที่ข้างในแทน)

```css
/* ใส่ที่หัวไฟล์ CSS ทุกโปรเจกต์เสมอ */
*, *::before, *::after {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}
```

## 4. ท่าไม้ตายที่เจอบ่อยที่สุด (Common Patterns)

1. **จัดกล่องให้อยู่กึ่งกลางหน้าจอแนวนอน:**
   ```css
   .card {
     max-width: 400px;
     margin: 0 auto; /* บนล่าง 0, ซ้ายขวา auto */
   }
   ```
2. **ปุ่มกดทรงสวย (Padding แนวนอนกว้างกว่าแนวตั้ง):**
   ```css
   button {
     padding: 0.6rem 1.2rem; /* บนล่าง 0.6rem, ซ้ายขวา 1.2rem */
   }
   ```
