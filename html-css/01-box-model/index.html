หน่วยวัดที่ใช้บ่อยใน CSS

  • px (Pixel): ค่าคงที่ เหมาะกับขอบเส้นบางๆ หรือไอคอนขนาดตายตัว
  • rem (Root EM): ยืดหยุ่นตามฟอนต์หลักของบราวเซอร์ นิยมใช้กับ padding, margin และ font-size
  • % (Percentage): ยืดหดตามขนาดของ Container แม่ เหมาะกับการทำ Responsive
