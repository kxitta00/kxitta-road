# 01-box-model (สัปดาห์ที่ 1)

เป้าหมาย: ฝึกเขียน HTML และ CSS จากศูนย์ด้วยมือตนเอง

---

## ภารกิจที่ต้องลงมือทำ

### 1. ไฟล์ index.html
- พิมพ์โครงสร้างพื้นฐาน HTML5 ด้วยตนเอง (เปิดแท็ก `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`)
- เชื่อมต่อไฟล์สไตล์ภายนอกด้วยแท็ก `<link rel="stylesheet" href="style.css">`
- สร้างกล่อง `<div>` ขึ้นมา 1 กล่อง แล้วใส่ข้อความไว้ข้างใน

### 2. ไฟล์ style.css
- ตั้งค่า Reset พื้นฐาน: `* { box-sizing: border-box; margin: 0; padding: 0; }`
- ใส่สไตล์ให้กล่องที่สร้าง:
  - กำหนด `width` และ `height`
  - กำหนด `background-color`
  - ทดลองใส่ `padding` เพื่อดูระยะห่างด้านในระหว่างข้อความกับขอบ
  - ทดลองใส่ `border` เช่น `2px solid red`
  - ทดลองใส่ `margin` เพื่อดูระยะห่างภายนอกระหว่างกล่องกับขอบจอ
- เปิดดูผลลัพธ์ผ่านเบราว์เซอร์ และลองคลิกขวา > Inspect (F12) เพื่อดูแผนผัง Box Model
