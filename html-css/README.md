# แผนผังการเรียนรู้ HTML & CSS

โฟลเดอร์สำหรับฝึกฝนทักษะการสร้างหน้าเว็บและจัด Layout ตาม Roadmap สู่การเป็น Web Developer

---

## โครงสร้างโฟลเดอร์

```
html-css/
├── 01-box-model/       สัปดาห์ที่ 1: Box Model, Margin, Padding, Units (px, rem, %), Typography
├── 02-flexbox/         สัปดาห์ที่ 2: การจัด Layout ด้วย Flexbox (Flex Container & Flex Items)
├── 03-css-variables/   สัปดาห์ที่ 3: ตัวแปร CSS, Hover Effects, Transitions
└── 04-css-grid/        ช่วงปิดเทอม: การจัดวาง Layout ตาราง 2 มิติด้วย CSS Grid
```

---

## แนวทางการฝึกฝน
1. เปิดไฟล์ `index.html` ด้วย Live Server ใน VS Code หรือดับเบิลคลิกเปิดบนเว็บเบราว์เซอร์
2. ฝึกแก้โค้ด CSS ในแต่ละหัวข้อ และสังเกตการเปลี่ยนแปลงบนหน้าจอจริงทันที
3. เน้นใช้ Semantic HTML (`header`, `main`, `section`, `article`, `footer`) แทนการใช้ `div` เพียงอย่างเดียว
