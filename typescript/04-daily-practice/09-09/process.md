# กระบวนการคิดและผังท่อข้อมูล (Data Flow Diagram & Thought Process)

## 1. Input Data & Edge Cases (วิเคราะห์ข้อมูลดิบและจุดดักขยะ)
<!-- บันทึกว่าข้อมูลดิบมีรูปแบบอย่างไร และจุดไหนบ้างที่เข้าข่ายข้อมูลขยะต้องคัดทิ้ง -->
ข้อมูลดิบ -> มีเลข id,ชื่อสินค้า,จำนวนที่ขายได้,ราคาสินค้า,สถานะ
สถานะ `PAID จ่ายแล้ว`, `PENDING รอดำเนินการ`, `CANCELLED ยกเลิก`, `REFUNDED คืนเงิน`
// จุดที่เป็นข้อมูลขยะต้องระวังและตัดทิ้ง >>นับว่าเป็นข้อมูลขยะ<<
เลขจำนวนสินค้าและเลขราคาสินค้า ->> ที่ติดลบ!!,แปลงเป็นตัวเลขแล้วได้ NaN

## 2. Processing Pipeline (ลำดับท่อการทำงาน)
<!-- อธิบายขั้นตอนทีละขั้น เช่น 
     Step 1: คลีนช่องว่างและแยกชิ้นส่วน
     Step 2: กรองข้อมูลขยะ (Corrupted Logs)
     Step 3: คำนวณยอดเงินและจัดกลุ่มสถานะ
-->
1. ฟังก์ชันคลีนข้อมูล >> นำข้อมูลดิบมาตัดช่องว่างหน้าหลังแล้วแยกชิ้นส่วนให้เป็นกลุ่มอาเรย์
2. ฟังก์ชันกรองข้อมูลขยะ >> นำข้อมูลที่ได้จากฟังก์ชันคลีนข้อมูลเข้ามาแปลงค่าตาม Object type แล้วแยกข้อมูลขยะออก
     // จุดที่เป็นข้อมูลขยะต้องระวังและตัดทิ้ง >>นับว่าเป็นข้อมูลขยะ<<
     เลขจำนวนสินค้าและเลขราคาสินค้า ->> ที่ติดลบ!!,แปลงเป็นตัวเลขแล้วได้ NaN,ดักยอดขายสินค้าที่ <=> 0
3. ฟังก์ชันคำณวนและจัดชุดข้อมูลส่งออกไป >> นำข้อมูลที่ผ่านการคัดแยกข้อมูลขยะออกแล้วมาทำการคำณวนแล้วส่งออกเป็น type Report

//สูตร 
สินค้าต้องมีสถานะ paid | quantity * unitPrice คำณวนราคารวมของแต่ละรายการ
## 3. Output Shape & Data Modeling (โครงสร้างข้อมูลและผลลัพธ์สุดท้าย)
<!-- ออกแบบ Type และรูปร่างของ Object รายงานสรุปที่ระบบต้องการ -->
enum Status {
     PAID = "PAID"
     PENDING = "PENDING"
     CANCELLED = "CANCELLED"
     REFUNDED = "REFUNDED"
}

type Product {
     id:string,
     productName:string,
     quantity:number,
     unitPrice:number,
     status:Status
}

type Report {
     totalLogs: จำนวนบันทึกทั้งหมดที่รับเข้ามา
     validLogs: จำนวนบันทึกที่ข้อมูลถูกต้อง
     corruptedLogs: จำนวนบันทึกที่เสียหาย/ถูกคัดทิ้ง
     totalRevenue: ยอดเงินรวมสุทธิของรายการที่ชำระเงินแล้ว 
     statusSummary:  {
          PAID :number
          PENDING = number
          CANCELLED = number
          REFUNDED = number
     }
     paidOrders: Product[]
}
