# คัมภีร์ฟังก์ชันสำเร็จรูป (Built-in Methods) ที่ใช้บ่อยที่สุด

ผมแบ่งระดับความสำคัญมาให้จากประสบการณ์ทำงานจริงครับ ฟังก์ชันพวกนี้คือสิ่งที่จะมาแทนที่การเขียน `for loop` ยาวๆ ให้เหลือแค่บรรทัดเดียว

---

## 🔥 เลเวล 1: MUST KNOW (ใช้ทุกวัน ขาดไม่ได้)
ถ้าจำพวกนี้ได้ ชีวิตการเขียนโปรแกรมจะสบายขึ้น 80%

### ฝั่งข้อความ (String)
- **`.split(ตัวแบ่ง)`** 
  - **ทำอะไร:** หั่นข้อความให้กลายเป็น Array
  - **ใช้บ่อยแค่ไหน:** ⭐️⭐️⭐️⭐️⭐️ (ใช้บ่อยสุดๆ เวลาต้องการจัดการทีละคำหรือทีละตัวอักษร)
  - **ตัวอย่าง:** `"Hello World".split(" ")` ➡️ `["Hello", "World"]`
- **`.toLowerCase()` / `.toUpperCase()`**
  - **ทำอะไร:** แปลงเป็นพิมพ์เล็กล้วน / พิมพ์ใหญ่ล้วน
  - **ใช้บ่อยแค่ไหน:** ⭐️⭐️⭐️⭐️⭐️ (ใช้ทุกครั้งที่ต้องเปรียบเทียบข้อความแบบไม่สนพิมพ์เล็กใหญ่)
- **`.includes(คำที่หา)`**
  - **ทำอะไร:** เช็คว่ามีคำนี้ซ่อนอยู่ในข้อความไหม (ได้ค่า `true`/`false`)
  - **ใช้บ่อยแค่ไหน:** ⭐️⭐️⭐️⭐️ (แทนการเขียนลูปหาคำ)
  - **ตัวอย่าง:** `"TypeScript".includes("Script")` ➡️ `true`
- **`.replace(คำเดิม, คำใหม่)` / `.replaceAll()`**
  - **ทำอะไร:** ค้นหาและแทนที่ข้อความ
  - **ใช้บ่อยแค่ไหน:** ⭐️⭐️⭐️⭐️
- **`.trim()`**
  - **ทำอะไร:** ตัดช่องว่างที่อยู่ "หัว" และ "ท้าย" ข้อความทิ้ง (ไม่ตัดตรงกลาง)
  - **ใช้บ่อยแค่ไหน:** ⭐️⭐️⭐️⭐️⭐️ (ใช้เสมอก่อนเอาข้อมูลที่ User พิมพ์มาลง Database ป้องกันคนเผลอกด Spacebar)

### ฝั่งอาเรย์ (Array)
- **`.join(ตัวเชื่อม)`**
  - **ทำอะไร:** เอา Array มาต่อกันให้กลายเป็นข้อความ (คู่หูของ `.split()`)
  - **ใช้บ่อยแค่ไหน:** ⭐️⭐️⭐️⭐️⭐️
  - **ตัวอย่าง:** `["A", "B", "C"].join("-")` ➡️ `"A-B-C"`
- **`.push(ค่า)` / `.pop()`**
  - **ทำอะไร:** เอาของยัดใส่ท้าย Array / เอาของชิ้นสุดท้ายออกจาก Array
  - **ใช้บ่อยแค่ไหน:** ⭐️⭐️⭐️⭐️⭐️
- **`.filter(เงื่อนไข)`**
  - **ทำอะไร:** คัดกรองของใน Array ให้เหลือเฉพาะที่ตรงเงื่อนไข
  - **ใช้บ่อยแค่ไหน:** ⭐️⭐️⭐️⭐️⭐️ (ใช้ตลอดเวลาที่อยากดึงข้อมูลที่สนใจออกมา)

## ⚡️ เลเวล 2: SHOULD KNOW (รู้ไว้ โค้ดจะหล่อขึ้นมาก)

### ฝั่งข้อความ (String)
- **`.substring(เริ่ม, จบ)` หรือ `.slice(เริ่ม, จบ)`**
  - **ทำอะไร:** หั่นเอาแค่ข้อความบางส่วนตาม Index ที่ระบุ
  - **ใช้บ่อยแค่ไหน:** ⭐️⭐️⭐️
  - **ตัวอย่าง:** `"TypeScript".slice(0, 4)` ➡️ `"Type"`
- **`.startsWith(คำ)` / `.endsWith(คำ)`**
  - **ทำอะไร:** เช็คว่าข้อความนี้ "ขึ้นต้นด้วย" หรือ "ลงท้ายด้วย" คำนี้ไหม
  - **ใช้บ่อยแค่ไหน:** ⭐️⭐️⭐️ (เช่น เช็คว่าเบอร์โทรขึ้นต้นด้วย "08" ไหม)

### ฝั่งอาเรย์ (Array)
- **`.map(การแปลงค่า)`**
  - **ทำอะไร:** เอาของทุกชิ้นใน Array มาแปลงร่างเป็นของใหม่ (จำนวนชิ้นเท่าเดิม)
  - **ใช้บ่อยแค่ไหน:** ⭐️⭐️⭐️⭐️⭐️ (ในโลกของการทำ Web Frontend เช่น React ใช้ตัวนี้แทบจะทุกนาที)
- **`.reverse()`**
  - **ทำอะไร:** กลับด้าน Array (หน้าไปหลัง)
  - **ใช้บ่อยแค่ไหน:** ⭐️⭐️
- **`.sort()`**
  - **ทำอะไร:** เรียงลำดับ Array (น้อยไปมาก / มากไปน้อย)
  - **ใช้บ่อยแค่ไหน:** ⭐️⭐️⭐️ (ใช้จัดอันดับข้อมูล)
