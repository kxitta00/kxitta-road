# 🗓️ ตารางฝึกซ้อมโปรแกรมเมอร์ (Weekly Problem-Solving Routine)

ตารางนี้ออกแบบมาเพื่อลบจุดอ่อนและเสริมจุดแข็งของคุณโดยเฉพาะ! กติกาคือ:
1. **ห้ามใช้เวลาเกิน 45 นาทีต่อข้อ** (ถ้าติดให้ถาม AI หรือดูเฉลยทันที)
2. **ห้ามใช้ for loop ดิบๆ** ในวันที่มีเขียนกำกับไว้
3. รันโค้ดและทดสอบเคสแปลกๆ ด้วยตัวเองเสมอ

---

## 🟢 วันจันทร์: String Manipulation (ลบจุดอ่อน)
**โจทย์: "เครื่องคัดกรองคำหยาบ (Profanity Filter)"**
*   **คำสั่ง:** สร้างฟังก์ชันรับข้อความเข้ามา ถ้าในข้อความมีคำว่า `"bad"`, `"ugly"`, `"stupid"` (ไม่สนพิมพ์เล็ก/ใหญ่) ให้เซ็นเซอร์คำนั้นเป็น `"***"`
*   **ตัวอย่าง:** 
    *   `filterWords("You are a BaD boy")` ➡️ `"You are a *** boy"`
    *   `filterWords("I am UGLY")` ➡️ `"I am ***"`
*   **คำใบ้:** ห้ามใช้ `for` ลูปไล่ตัวอักษร ให้ใช้ `.replace()` หรือ `.replaceAll()` ร่วมกับ Regex (ลองเสิร์ชหาดูนะ)

## 🟡 วันอังคาร: Array Modern Methods (สั่งห้ามใช้ for loop!)
**โจทย์: "ระบบประกาศผลสอบ (Exam Results)"**
*   **คำสั่ง:** มี Array ของ Object นักเรียน `[{name: "A", score: 45}, {name: "B", score: 80}, {name: "C", score: 65}]`
    1. ให้ดึงมาเฉพาะนักเรียนที่สอบผ่าน (คะแนน >= 50)
    2. แล้วแปลงให้ออกมาเป็นแค่ Array ของชื่อ (เช่น `["B", "C"]`)
*   **กติกาเหล็ก:** ห้ามใช้ `for (...)` หรือ `forEach` เด็ดขาด!
*   **คำใบ้:** ใช้ `.filter()` ต่อด้วย `.map()` แบบรวดเดียวจบ (Chaining)

## 🟠 วันพุธ: Data Aggregation (จุดแข็งของคุณ)
**โจทย์: "สรุปยอดโหวตผลไม้ (Fruit Vote Counter)"**
*   **คำสั่ง:** รับ Array สตริง `["apple", "banana", "apple", "orange", "banana", "apple"]` ให้สรุปว่าแต่ละอย่างได้กี่โหวต
*   **ผลลัพธ์ที่คาดหวัง:** `{ apple: 3, banana: 2, orange: 1 }`
*   **คำใบ้:** สร้างตัวแปร Object ว่างๆ `{}` แล้ววนลูปเช็คว่าถ้ายังไม่มีชื่อผลไม้ใน Object ให้เซ็ตเป็น 1 แต่ถ้ามีแล้วให้บวก 1

## 🔴 วันพฤหัสบดี: Edge Cases & Validation (นักจับผิด)
**โจทย์: "เครื่องคิดเลขหารสัดส่วนที่ไม่มีวันพัง (Unbreakable Divider)"**
*   **คำสั่ง:** สร้างฟังก์ชันรับตัวเลข 2 ตัว `(a, b)` เพื่อเอามาหารกัน (`a / b`) แต่มันต้องดักการพังทุกรูปแบบ:
    1. ถ้าใส่ `b = 0` ให้ return `"Error: Cannot divide by zero"`
    2. ถ้ามีใครแอบส่งค่ามาเป็น String เช่น `divide(10, "2")` ให้ return `"Error: Numbers only"`
    3. ถ้าค่าว่างเปล่า (null/undefined) ให้ return `"Error: Missing inputs"`

## 🔵 วันศุกร์: Business Logic (กฎโลกความจริง)
**โจทย์: "ตู้เก็บค่าจอดรถอัตโนมัติ (Parking Fee Calculator)"**
*   **คำสั่ง:** รับชั่วโมงที่จอด (เป็นตัวเลขทศนิยมได้ เช่น 2.5 ชั่วโมง) 
    *   1 ชั่วโมงแรก ฟรี!
    *   ชั่วโมงถัดไป คิดชั่วโมงละ 20 บาท (เศษของชั่วโมงปัดขึ้นเป็น 1 ชั่วโมงเต็มเสมอ เช่น จอด 1.2 ชั่วโมง ถือเป็น 2 ชั่วโมง)
    *   ถ้าจอดเกิน 8 ชั่วโมง ให้เหมาจ่ายแค่สูงสุด 150 บาท
*   **คำใบ้:** ใช้ `Math.ceil()` เพื่อปัดเศษขึ้น และใช้ `if-else` เรียงลำดับให้ดี

## 🟣 วันเสาร์: Mini-Integration (รวมร่าง)
**โจทย์: "ระบบสรุปบิลตะกร้าสินค้า (Smart Cart Checkout)"**
*   **คำสั่ง:** รับข้อมูล Array สินค้า `{ name, price, type }` (type มี "food" กับ "electronic")
    1. ถ้ายอดรวมทั้งหมดเกิน 1,000 บาท ให้ลด 10%
    2. แต่มีกฎว่า "สินค้า type: food จะไม่ถูกนำมารวมเพื่อคิดส่วนลด 10%" (ลดแค่อิเล็กทรอนิกส์)
    3. รีเทิร์น Object สรุปบิล `{ totalBeforeDiscount: 1500, discountValue: 100, netTotal: 1400 }`
*   **ความท้าทาย:** คุณต้องใช้ความรู้ตั้งแต่วันจันทร์-ศุกร์ มารวมไว้ในฟังก์ชันเดียว

## ⚪ วันอาทิตย์: Rest & Code Review (ขโมยวิชา)
*   **ไม่ต้องพิมพ์โค้ดใหม่:** ให้ก๊อปปี้โค้ดของวัน อังคาร หรือ เสาร์ ของคุณ
*   **สิ่งที่ต้องทำ:** โยนโค้ดนั้นมาให้ AI (หรือผม) แล้วสั่งว่า *"นี่คือโค้ดของผม ช่วย Review แล้วบอกหน่อยว่ามีวิธีเขียนให้โค้ดนี้หล่อขึ้น หรือสั้นลงกว่าเดิมไหม?"*
*   **เป้าหมาย:** ซึมซับ "ท่าใหม่ๆ" เข้าคลังสมอง
