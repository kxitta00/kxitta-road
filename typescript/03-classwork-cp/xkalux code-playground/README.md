# Terminal Quest

A text-based adventure game for the terminal.

Basic Programming Examples
- No OOP (Object-Oriented Programming) style.
- No FP (Functional Programming) style.
- just simple functions and data structures.
- basic programming concepts like loops, conditionals, and variables.

## Installation

run bun update to install the dependencies.
```cmd
bun update
```

run bun start to start the game.
```cmd
bun start
```

# เทอมินัลควสท์ (Terminal Quest) 

เป็นเกมผจญภัยแบบข้อความที่เล่นในเทอร์มินัล 

เรียนรู้แนวคิดการเขียนโปรแกรมพื้นฐาน เช่น การใช้ตัวแปร การใช้เงื่อนไข การใช้ลูป และการสร้างฟังก์ชัน โดยไม่ใช้แนวคิด OOP (Object-Oriented Programming) หรือ FP (Functional Programming) เพื่อให้ผู้เล่นสามารถเข้าใจและเรียนรู้การเขียนโปรแกรมได้ง่ายขึ้น   

## การติดตั้ง
รันคำสั่ง `bun update` เพื่อติดตั้ง dependencies ของเกม
```cmd
bun update
```

รันคำสั่ง `bun start` เพื่อเริ่มเล่นเกม
```cmd
bun start
```
