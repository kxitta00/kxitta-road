## โจทย์ข้อที่ 52: ระบบศูนย์คัดแยกและจัดส่งพัสดุด่วนอัจฉริยะ (Smart Parcel Dispatch Engine)

## input {
  parcelId(รหัสพัสดุ) 
  recipientCity(เมือง/จังหวัดปลายทาง)  
  shippingTier(ประเภทความเร็วในการจัดส่ง) 
  weightKg (น้ำหนักพัสดุ) 
  hasFragileInsurance?( ซื้อประกันพัสดุแตกหักเสียหายหรือไม่)
  isCancelled?ลูกค้ายกเลิกพัสดุหรือไม่
## }

## output {
  totalShippingRevenue (รายได้ค่าจัดส่งรวมสุทธิทั้งหมด)
  totalDispatchedParcels(จำนวนพัสดุที่จัดส่งสำเร็จ)
  cancelledParcelsCount(จำนวนพัสดุที่ถูกยกเลิก)
  totalWeightKg( น้ำหนักพัสดุรวมทั้งหมดที่ส่งสำเร็จ (kg))
  fragileInsuranceRevenue(รายได้เฉพาะค่าประกันพัสดุแตกหักทั้งหมด)
  topDestinationCity(จังหวัดปลายทางที่สร้างรายได้ค่าส่งสูงสุดอันดับ 1)
## }

## Process {
  ## 1.ตรวจสอบข้อมูลที่เข้ามา
  -> ต้องมีรายการเข้ามาอย่างน้อย 1 รายการ
  -> ถ้าน้อยกว่า1 ให้คืนค่าเริ่มต้น

  ## 2.คำณวนหาผลรวมต่างๆ
  -> มีเคสไหนถูกยกเลิกมั้ย? (isCancelled === true?)
  -> ถ้าถูกยกเลิกให้ข้ามเคสนั้นพร้อมนับสะสมจำนวนเคสที่ถูกยกเลิก +1 (continue AND cancelledParcelsCount += 1 )
  -> ถ้าไม่ถูกยกเลิกให้นำเคสนั้นมาคำณวนต่อพร้อมนับสะสมเคสสำเร็จ +1 (totalDispatchedParcels += 1)

  -> ตรวจสอบประเภทการจัดส่ง (shippingTier?)?
  -> ประกาศ ratePerKg เก็บหน่วยคิดเงินต่อกิโลกรัม 
  -> ถ้า "STANDARD" ratePerKg = 30
  -> ถ้า "EXPRESS" ratePerKg = 60
  -> ถ้า "SAME_DAY" ratePerKg = 100
  -> ประกาศ parcelCost เก็บนำ้หนักพัสดุชิ้นนี้(สูตร ratePerKg * weightKg)

  -> มีประกันพัสดุเสียหายด้วยมั้ย? (hasFragileInsurance === true?)
  -> ประกาศ fragileInsuranceRevenue เก็บผลรวมค่าประกันทั้งหมด
  -> ถ้ามี parcelCost + 80 และเก็บสะสมค่าประกันพัสดุไว้ใน fragileInsuranceRevenue += 80
  -> ถ้าไม่มี ไม่เก็บเพิ่ม parcelCost + 0 และ fragileInsuranceRevenue += 0

  -> ประกาศ totalShippingRevenue เก็บผลรวมพัสดุทั้งหมด (+= parcelCost)
  -> ประกาศ totalWeightKg เก็บผลรวมนำหนักทั้งหมด (+= weightKg)
  -> ประกาศ cityRevenueMap[recipientCity] เก็บผลรวมแยกตามจังหวัดปลายทาง (+= parcelCost)
  -> ถ้าใน cityRevenueMap[recipientCity] ยังไม่มีชื่อจังหวัดนั้น
  -> ให้ cityRevenueMap[recipientCity] = 0
  -> หลังจากนั้น cityRevenueMap[recipientCity] += parcleCost

  ## 3.นำผลรวมแยกตามจังหวัดปลายทางมาหา จังหวัดที่ทำเงินอันดับ1
  -> ประกาศ maxCost ไว้เก็บเก็บจำนวนเงินที่เยอะที่สุดของจังหวัดแชมป์
  -> ประกาศ cityName เพื่อเก็บชื่อจังหวัดทั้งหมดดึงมาจาก cityRevenueMap[recipientCity]
  -> เรียก topDestinationCity มาไว้เก็บชื่อจังหวัด

  -> ถ้ายอดเงินจังหวัดไหนเยอะที่สุดให้
  maxCost = ยอดเงินจังหวัดนั้น
  topDestinationCity = ชื่อจังหวัดนั้น

  -> return ค่าที่หามาแล้วทั้งหมด
## }

## Variable {
  //ส่วนเก็บผลรวม
  totalShippingRevenue (รายได้ค่าจัดส่งรวมสุทธิทั้งหมด)
  totalDispatchedParcels(จำนวนพัสดุที่จัดส่งสำเร็จ)
  cancelledParcelsCount(จำนวนพัสดุที่ถูกยกเลิก)
  totalWeightKg( น้ำหนักพัสดุรวมทั้งหมดที่ส่งสำเร็จ (kg))
  fragileInsuranceRevenue(รายได้เฉพาะค่าประกันพัสดุแตกหักทั้งหมด)

  //ส่วนใช้ชั่วคราวเพื่อนำไปหาผลรวม
  ratePerKg (ราคาต่อกิโลกรัม)
  parcelCost (ราคาพัสดุชิ้นนั้น)

  //ส่วนหาแชมป์
  cityName เพื่อเก็บชื่อจังหวัดทั้งหมดดึงมาจาก cityRevenueMap[recipientCity]
  maxCost = ยอดเงินจังหวัดนั้น
  topDestinationCity(จังหวัดปลายทางที่สร้างรายได้ค่าส่งสูงสุดอันดับ 1)
## }
