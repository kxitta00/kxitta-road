## โจทย์ข้อที่ 54: ระบบสรุปยอดออเดอร์ร้านอาหารและเดลิเวอรี 

## input {
  ประกาศ interface OderItem (รายการอาหารย่อยในออเดอร์)
  itemName ชื่อเมนู
  quantity จำนวนจานที่สั่ง
  unitPrice ราคาต่อจาน

  ประกาศ interface RestaurantOrder (ออเดอร์หลัก)
  orderId รหัสออเดอร์
  customerTier ระดับสมาชิกมี ("REGULAR" | "SILVER" | "GOLD") => (ลด 0% | ลด 10% | ลด 20% )
  items[] รายการอาหารที่สั่งในออเดอร์ (Array ซ้อนอยู่ข้างใน!)
  hasExpressDelivery? สั่งส่งด่วนพิเศษหรือไม่ (ถ้า true +60 บาท ค่าส่งนี้ไม่รวมในลดราคา)
  isVoided? ออเดอร์ถูกยกเลิก/โมฆะหรือไม่ (ถ้า true ให้ข้ามไม่คิดเงิน)

## }

## output {
  ประกาศ interface RestaurantReport (คืนค่าตามที่ต้องการ)
  totalNetRevenue (รายได้สุทธิรวมทั้งหมดของร้าย (ค่าอาหารหลังหักส่วนลด + ค่าส่งด่วนถ้ามี!))
  totalCompletedOrders (จำนวนออเดอร์ที่สั่งสำเร็จ)
  voidedOrdersCount (จำนวนออเดอร์ที่ถูกยกเลิก)
  totalDishesSold (จำนวนจารอาหารทั้งหมดที่ขายได้)
  totalDiscountGiven (มูลค่าส่วนลดสมาชิกรวมทั้งหมดที่ร้านมอบให้ลูกค้า)
  topGrossingItem (ชื่อเมนูอาหารที่สร้างยอดขายดิบรวมสูงสุดอันดับ 1)
## }

## Process {
 1. ถ้าไม่มีออเดอร์เข้ามาเลย
  -> คืนค่าเริ่มต้น (topGrossingItem: "No Data")

 2. ออเดอร์ถูกยกเลิกมั้ย? (isVoided?)
 yes -> ข้ามการคิดเงินออเดอร์นั้น(continue)และสะสมยอดยกเลิกออเดอร์ + 1 (voidedOrdersCount += 1)
 no -> นำออเดอร์นั้นมาคิดเงินต่อและสะสมยอดออเดอร์สำเร็จ + 1 (totalCompletedOrders += 1)

 3. เช็ครายการอาหารย่อยในออเดอร์ (order.items)
  หายอดรวมค่าอาหารดิบด้วยจำนวนจานที่สั่งคูณราคาต่อจาน (rawFoodTotal += (quantity * unitPrice))
  นับจำนวนจานรวม (orderDishes += quantity)
  สะสมยอดขายดิบแยกตามชื่อเมนู (itemRevenueMap) 
  -> ถ้ายังไม่มีชื่อเมนูนี้ใน Map -> ให้ตั้งค่าเริ่มต้นเป็น 0 (itemRevenueMap[item.itemName] = 0) 
  -> หลังจากนั้น บวกยอดขายเมนูนี้เข้าไปเสมอ -> itemRevenueMap[item.itemName] += (quantity * unitPrice)

  4. คิดส่วนลดสมาชิกตามเทียร์ (customerTier?)
  สูตร (discount = ยอดอาหารดิบมา * ส่วนลด? | discount = rawFoodTotal * 0.00%?)
  -> "REGULAR" -> discount = (rawFoodTotal * 0.00) //ลด 0%
  -> "SILVER" -> discount = (rawFoodTotal * 0.10) //ลด 10%
  -> "GOLD" -> discount = (rawFoodTotal * 0.20) ////ลด 20%

  5. มีค่าบริการส่งด่วนพิเศษมั้ย? (hasExpressDelivery?)
  yes -> (ค่าส่ง)expressFee = 60
  no -> (ค่าส่ง)expressFee = 0

  6. สะสมยอดรวมสุทธิของออเดอร์นี้ 
  -> ค่าอาหารดิบลบส่วนลดบวกค่าส่ง = ยอดรวมออเดอร์นี้ (orderNetTotal = (rawFoodTotal - discount) + expressFee)

  7. สะสมยอดรวมภาพรวมทั้งหมด
  -> สะสมรายได้สุทธิรวมด้วยการนำยอดรวมแต่ละออเดอร์มาบวกสะสม (totalNetRevenue += orderNetTotal)
  -> สะสมจำนวนจานรวมด้วยการนำยอดจานแต่ละเดอร์มาบวกสะสม (totalDishesSold += orderDishes)
  -> สะสมมูลค่าส่วนลดรวมด้วยการนำยอดส่วนลดมาบวกสะสม (totalDiscountGive += discount)

  8. หาเมนูที่ขายดีที่สุดอันดับ 1 ในรายการนี้
  -> ดึงชื่อเมนูทั้งหมดมาจาก itemRevenueMap ด้วย itemsName = Object.keys(itemRevenueMap)
  -> เมนูแชมป์ตอนนี้น้อยกว่าเมนูผู้ท้าชิง? (maxCost < itemRevenueMap[itemsName]?)
  yes -> เมนูแชมป์ = เมนูใหม่จากผู้ท้าชิง (topGrossingItem = itemsName)
         ราคาเมนูแชมป์ = ราคาใหม่จากผู้ท้าชิง (maxCost = itemRevenueMap[itemsName])
  no -> เมนูแชมป์ = เมนูแชมป์
        ราคาเมนูแชมป์ = ราคาเมนูแชมป์
        ไปเช็คเมนูถัดไป

  9. คืนค่า (return)
  
  totalNetRevenue (รายได้สุทธิรวมทั้งหมดของร้าย (ค่าอาหารหลังหักส่วนลด + ค่าส่งด่วนถ้ามี!))
  totalCompletedOrders (จำนวนออเดอร์ที่สั่งสำเร็จ)
  voidedOrdersCount (จำนวนออเดอร์ที่ถูกยกเลิก)
  totalDishesSold (จำนวนจารอาหารทั้งหมดที่ขายได้)
  totalDiscountGiven (มูลค่าส่วนลดสมาชิกรวมทั้งหมดที่ร้านมอบให้ลูกค้า)
  topGrossingItem (ชื่อเมนูอาหารที่สร้างยอดขายดิบรวมสูงสุดอันดับ 1)


## }
